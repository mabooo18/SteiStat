%%Research highlights
\begin{highlights}
\item Steistat is an open-source, AD5941/RP2040 potentiostat built directly
  from Analog Devices' own evaluation-kit reference firmware.
\item Eleven firmware defects were diagnosed by direct comparison against
  that vendor reference and fixed, including a calibration-resistor
  declaration that silently scaled every reported current by $+424\,\%$.
\item All six electrochemical-method classes now share one polymorphic
  C++ base class, and the central parameter store is fully
  field-encapsulated -- closing every gap this project's own
  object-oriented audit had raised.
\item Cyclic voltammetry against a traceable Randles dummy cell recovers
  $R=\SI{10605.1\pm0.9}{\ohm}$ against a \SI{10560}{\ohm} nominal value
  ($+0.427\,\%$ error, $R^2\geq0.9999986$), independently reproducing an
  earlier measurement on the same corrected firmware.
\item A real, currently open limitation is reported honestly: sustained
  CA/SWV/DPV current does not track the applied potential, unlike its own
  correctly step-dependent transient onset.
\end{highlights}

\section*{Data and code availability}
The pre-fix and post-fix firmware source for \texttt{C\_CA}/\texttt{C\_SWV}/
\texttt{C\_DPV}/\texttt{C\_DCPotentiostatMethod}, the code-comparison notes
against the Analog Devices reference examples, this paper's own raw
dummy-cell serial logs (chronoamperometry, cyclic voltammetry against both
the \SI{10}{\kilo\ohm} resistor and the Randles cell, square-wave and
differential-pulse voltammetry), and all hardware design files (schematic,
PCB, Gerbers, BOM, pick-and-place) are available in the project repository,
\url{https://github.com/mabooo18/SteiStat}.
