%%Research highlights
\begin{highlights}
\item Steistat is an open-source, AD5941/RP2040 potentiostat built directly
  from Analog Devices' own evaluation-kit reference firmware.
\item The complete hardware design files, bill of materials, and
  firmware source are openly available, enabling independent
  reproduction and further development of the Steistat platform.
\item Across all four electrochemical methods -- cyclic voltammetry (CV),
  chronoamperometry (CA), square-wave voltammetry (SWV), and differential
  pulse voltammetry (DPV) -- the corrected signal chain produces
  correctly-signed, non-degenerate output on real hardware.
\item Cyclic voltammetry against a traceable Randles dummy cell recovers
  $R=\SI{10605.1\pm0.9}{\ohm}$ against a \SI{10560}{\ohm} nominal value
  ($+0.427\,\%$ error, $R^2\geq0.9999986$), independently reproducing an
  earlier measurement on the same corrected firmware.
\item Measurement latency is bounded and datasheet-matched: each
  conversion settles within $\approx$\SI{13.3}{\milli\second}
  ($\approx$\SI{75}{\hertz} ceiling), with every previously unbounded wait
  loop now timeout-protected; against a plain \SI{10}{\kilo\ohm} resistor,
  the same corrected chain recovers $R=\SI{10005.9}{\ohm}$
  ($+0.06\,\%$ error, $R^2=0.9999988$).
\end{highlights}

\section*{Data and code availability}
The pre-fix and post-fix firmware source for \texttt{C\_CA}/\allowbreak
\texttt{C\_SWV}/\allowbreak\texttt{C\_DPV}/\allowbreak
\texttt{C\_DCPotentiostatMethod}, the code-verification notes
against the Analog Devices reference examples, this paper's own raw
dummy-cell serial logs (chronoamperometry, cyclic voltammetry against both
the \SI{10}{\kilo\ohm} resistor and the Randles cell, square-wave and
differential-pulse voltammetry), and all hardware design files (schematic,
PCB, Gerbers, BOM, pick-and-place) are available in the project repository,
\url{https://github.com/mabooo18/SteiStat}.
